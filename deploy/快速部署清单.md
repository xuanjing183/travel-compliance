# 快速部署清单

> 拖拽上传 + 7 步服务器操作，完成部署。

---

### 第 1 步：本地拖拽上传

用 SFTP 工具（WinSCP / MobaXterm / FinalShell 等）将本地文件夹拖到服务器：

- **本地**：`C:\Users\22316\Desktop\1\lc-course\travel-compliance-desk`
- **服务器**：`/opt/travel-compliance-desk`

---

### 第 2 步：SSH 登录服务器

```bash
ssh root@服务器IP
```

---

### 第 3 步：安装 Docker

```bash
yum install -y yum-utils
yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
yum install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
systemctl enable --now docker
```

验证：
```bash
docker --version && docker compose version
```

---

### 第 4 步：配置环境变量

```bash
cd /opt/travel-compliance-desk
cp .env.example .env
vi .env
```

填写以下内容（real+live 模式）：
```env
# 必填
DASHSCOPE_API_KEY=sk-你的真实密钥
TRAVEL_DESK_LLM_MODE=real
TRAVEL_DESK_PROVIDER_MODE=live

# Live 供应商密钥（必填）
TRAVEL_DESK_TAVILY_API_KEY=你的Tavily密钥
TRAVEL_DESK_QWEATHER_API_HOST=你的和风天气API Host
TRAVEL_DESK_QWEATHER_API_KEY=你的和风天气API Key
```

---

### 第 5 步：开放端口

```bash
firewall-cmd --permanent --add-port=8000/tcp && firewall-cmd --reload
```

> 云安全组也要放行 8000。

---

### 第 6 步：一键构建并启动

```bash
cd /opt/travel-compliance-desk/deploy
bash deploy.sh
```

等待看到 `=== 部署成功 ===`。

---

### 第 7 步：验证

浏览器访问 `http://服务器IP:8000`

或命令行测试：
```bash
curl http://localhost:8000/api/health
```

---

### 日常运维

```bash
cd /opt/travel-compliance-desk/deploy

docker compose logs -f        # 看日志
docker compose restart         # 重启
docker compose down            # 停止（数据不丢）
docker compose up -d           # 启动
docker compose ps              # 查状态
```

---

### 更新代码

1. 本地修改代码后，重新拖拽上传覆盖服务器文件
2. 服务器执行：

```bash
cd /opt/travel-compliance-desk/deploy
docker compose build --no-cache
docker compose up -d
```
